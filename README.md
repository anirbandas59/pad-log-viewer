# PAD Log Viewer

A single self-contained HTML file that turns a Power Automate Desktop run-log CSV into an interactive review screen, entirely in the browser. No install, no server, no data leaves the machine.

- **Reviewers:** download `pad-log-viewer-vX.Y.Z.html` from a release and open it in Edge or Chrome. (Full reviewer guide arrives in M8.)
- **Contributors:** Node 24 (`nvm use`), then `npm ci`, `npm run dev`, and `npm run check` before a PR.
